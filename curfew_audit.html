First Responder Interception (The NSTextView Trap)

When typing in a task field, NSTextView eats Escape as cancelOperation:, starving the window's keyDown.

1. The Accessory App Activation Void
Critical Trap
Configured as .accessory, the app lacks standard Dock or menubar activation. An elevated borderless window covers all pixels, but if macOS transfers focus to a background process, user keystrokes are routed into the void.
Architecture Fix Use Carbon global hotkeys (Cmd+Shift+Esc) that operate at WindowServer level without requiring app activation.
2. NSTextView First-Responder Trap
Critical Trap
When typing intent into the late-night request box, NSTextView acts as the first responder and consumes Escape, preventing window keydown handlers from running.
Architecture Fix Override cancelOperation(_:) and performKeyEquivalent(with:) on the window to catch Escape before child views consume it.
3. Multi-Monitor Asymmetric Focus
Critical Trap
Secondary screens received blank shield windows with canBecomeKey = true. Clicking a secondary screen made the empty window key, freezing typing in the primary card.
Architecture Fix Enforce canBecomeKey = false on secondary windows and redirect all clicks to refocus the primary card.
4. RunLoop Starvation of Safety Timers
Timing Bug
Default Timer.scheduledTimer runs on .default RunLoop mode. Any modal drag, mouse tracking, or menu click pauses the timer, preventing auto-dismiss from firing.
Architecture Fix Schedule all timers on RunLoop.main in .common mode for uninterrupted execution.
5. The Bedtime Re-Lock Loop
State Trap
Exiting test mode between 10 PM and 5 AM immediately re-evaluated realCurfew == true, locking the screen again on the next line of code without test safeguards.
Architecture Fix Implemented isCurfewManuallySuppressed flag to break state loops until deliberate reset or morning rollover.
6. Stale Display Geometry on Hotplug
Window Glitch
Connecting or disconnecting displays or closing MacBook lid left windows with stale dimensions, causing black clipping boxes or exposed unshielded areas.
Architecture Fix Observer for didChangeScreenParametersNotification to dynamically recreate window frames.

Interactive Findings & Scope Rationalization

Detailed inventory of system risks, fragile IPC mechanisms, and candidate features for deprecation vs. enhancement.

Accessibility TCC Silent Failure
Critical Trap
NSEvent.addGlobalMonitorForEvents silently yields zero events if the app lacks Accessibility permissions in System Settings. When launched from Terminal or debug builds, global hotkeys failed without error.
Remedy Implemented Carbon RegisterEventHotKey delivers global shortcuts at WindowServer level with zero permission prompts required.
Modal Tracking Starvation
Critical Trap
Safety countdowns and test auto-dismissals scheduled on .default RunLoop mode stopped executing whenever a user clicked, dragged, or opened a menu.
Remedy Implemented All countdown and safety timers now explicitly register with RunLoop.main in .common mode.
Field Editor Keyboard Trapping
Critical Trap
Clicking into text fields transferred first responder to NSTextView, which ate Escape keys as cancel operations, preventing the user from escaping test mode.
Remedy Implemented Overrode performKeyEquivalent and cancelOperation directly on the custom window subclass.
Bedtime State Machine Re-Lock Trap
Critical Trap
Exiting a test lock between 10:00 PM and 5:00 AM immediately called lockAllScreens(isTestMode: false), re-engaging hard curfew on the very next line of code without test safeguards.
Remedy Implemented Added isCurfewManuallySuppressed state flag that survives until morning wake or deliberate re-engagement.
Secondary Display Focus Hijack
Critical Trap
Clicking a secondary display made a headless window the key window, preventing user keystrokes from reaching the interactive card on the primary display.
Remedy Implemented Disabled key status on secondary windows (canBecomeKey = false) and routed clicks to refocus the primary card.
AppleScript SMS Injection (Messages.app)
Permissions Fragility
EmergencySMSBridge.swift executes raw AppleScript to drive Messages.app. On macOS 14+, AppleScript automation triggers TCC prompts that can stall or fail silently if permissions are rejected.
Recommendation Gracefully handle AppleScript execution errors and provide a fallback local visual notification alert.
AppleScript Reminders Automation
Permissions Fragility
RemindersBridge.swift uses AppleScript string concatenation to create reminders. String escaping can fail on unexpected input, and automation permissions can fail.
Recommendation Replace AppleScript automation with Apple's native EventKit framework (EKEventStore) for type-safe, direct reminder creation.
Hardcoded SQLite HealthKit Database Path
Architectural Fragility
HealthContextBridge.swift directly reads /Users/jakedarrow/Developer/PersonalTrainer/data/healthkit_history.db. If the file is locked, moved, or has schema changes, it silently falls back.
Recommendation Establish a standardized JSON export or shared App Group container instead of raw SQLite path coupling across projects.
Plaintext TCP Local Bridge Server (Port 48200)
Security / Network
LocalBridgeServer.swift listens on unauthenticated HTTP on port 48200 with wildcard CORS (Access-Control-Allow-Origin: *). Any webpage in any browser could query or alter focus mode.
Recommendation Add a shared token secret or migrate to Native Messaging / URL schemes (curfew://).
Wi-Fi SSID Location Profiling
Deferred by User
WiFiTracker.swift uses CoreWLAN CWWiFiClient to inspect SSIDs. While flagged as a potential scope reduction, user opted to keep it in the codebase for potential future implementation.
Decision: Defer (Retained) Kept intact in codebase (WiFiTracker.swift) per user direction. Not deprecated or removed.
Browser Extension IPC Bridge (Port 48200)
Deferred by User
The port 48200 local TCP server exists to communicate with browser extensions. User opted to retain this infrastructure in the codebase for potential future extension integrations.
Decision: Defer (Retained) Kept intact in codebase (LocalBridgeServer.swift) per user direction. Not deprecated or removed.
CUT: Weekend App Whitelist Rules
Scope Rationalization
Config.weekendAllowedApps defined lists of apps (Xcode, Logic Pro, etc.) but was never actually enforced in UI. Over-complicated rules dilute the core promise: sleep recovery.
Decision: Cut / Simplify Remove unused weekend whitelists. Keep weekends completely unrestricted so Curfew does one job perfectly: weeknight sleep.
POLISH: Pre-Lock Warning Experience
Implemented
Screen lockouts must never feel jarring. Pre-lock warnings at 15m, 5m, and 1m allow users to save audio projects or code branches gracefully before curfew hits.
Implemented in Code & Mockup Floating amber HUD pill with soothing golden glow (`#FBBF24`), stress-free copy ("Curfew in 5 minutes • Wrap up work"), zero alarming icons, and "Got It" action.
POLISH: Sleep Context & "Smart No" Arbitration
Implemented
The agency intent template ("I need X mins so I can Y...") evaluated against 7-day sleep debt is the crown jewel feature. Denied requests automatically schedule follow-up tasks.
Implemented with Native EventKit Converted RemindersBridge.swift to Apple's native EventKit (EKEventStore) with AppleScript fallback, eliminating scripting injection bugs.
POLISH: Standalone Menu Bar Experience
Implemented
The menu bar item is the primary interface. Upgrading from plain text to dynamic SF Symbols with clear status popovers makes Curfew feel like an Apple-designed utility.
Implemented in Code Dynamic SF Symbols (hourglass, timer, moon.zzz.fill), active screen time counter eliminated, and safe sandbox preview actions integrated.

Architectural Decision Checkpoints

Interactive voting matrix to establish consensus on scope reductions, framework choices, and IPC security.

Decision Topic Proposed Architectural Recommendation Decision
1. Deprecate Wi-Fi SSID Tracking
Eliminate CoreWLAN location prompt
 Remove WiFiTracker.swift and CoreWLAN framework. Curfew operates purely on calendar time (10:00 PM to 5:00 AM on weeknights), eliminating privacy-invasive Location Services prompts.
2. Deprecate Local TCP Server (Port 48200)
Eliminate local open socket & CORS
 Remove LocalBridgeServer.swift. YouTube distraction blocking is handled natively by the Safari userscript; removing the HTTP server eliminates a localhost attack vector and background network listening.
3. Replace AppleScript with Native EventKit
Type-safe reminders creation
 Migrate RemindersBridge.swift from executing raw AppleScript to Apple's native EventKit framework. Eliminates AppleScript parsing bugs and uses official macOS calendar/reminder permissions.
4. Modular Swift Package Structure
CurfewCore + CurfewApp targets
 Refactor Package.swift into a library target CurfewCore (arbitration, storage, window controllers) and an executable target CurfewApp. Enables standard swift test automated unit test suites.
5. Retain Carbon Global Hotkeys
Cmd+Shift+Esc developer safeguard
 Keep SafetyBypassManager permanently integrated in all debug and release builds to ensure developers and users can never be trapped by an unexpected overlay freeze.
